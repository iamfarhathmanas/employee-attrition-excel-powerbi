# Excel Analysis

## KPI formulas
- Total Employees: `=COUNTA(EmployeeData[Employee_ID])`
- Employees Left: `=COUNTIF(EmployeeData[Left_Company],"Yes")`
- Attrition Rate: `=Employees Left/Total Employees`
- Average Salary: `=AVERAGE(EmployeeData[Salary])`
