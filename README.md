# Employee Attrition Analysis — Excel & Power BI

An Excel and Power BI HR analytics portfolio project focused on employee attrition across department, job level, tenure, salary, work mode and overtime.

## Tools
- Microsoft Excel
- Microsoft Power BI

## Excel Analysis
- Structured employee dataset
- Attrition KPIs
- Department-level analysis
- Dashboard-oriented summary

## Power BI Dashboard
Recommended visuals:
- Total Employees
- Employees Left
- Attrition Rate
- Average Salary
- Attrition by Department
- Attrition by Job Level
- Attrition by Tenure Group
- Attrition by Work Mode
- Attrition by Overtime
- Salary vs Attrition
- Slicers for Department, Job Level, Work Mode and Overtime

## Dataset Note
Generated practice data for portfolio demonstration; it is not employer/client data.
