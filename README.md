# Employee Attrition Analysis — Excel + Power BI Portfolio Project

## Executive Summary
A practical HR analytics project demonstrating employee attrition analysis through structured Excel reporting and Power BI dashboard design.

## Objective
Understand workforce attrition patterns across department, job level, tenure, performance, salary, work mode, and overtime.

## Analytics Workflow
**Data → Validation → Excel Analysis → KPI Design → Power BI Reporting → HR Insights**

## Excel Scope
- Structured employee dataset
- Attrition KPI calculations
- Department analysis
- Tenure-group analysis
- Power BI-ready source workbook

## Power BI Dashboard Scope
- Total Employees
- Employees Left
- Attrition Rate
- Average Salary
- Attrition by Department
- Attrition by Job Level
- Attrition by Tenure Group
- Attrition by Work Mode
- Attrition by Overtime
- Salary analysis
- Interactive slicers for Department, Job Level, Work Mode, Overtime, and Tenure Group

## Recommended Reporting Flow
1. Workforce overview
2. Attrition drivers
3. Department and tenure comparisons
4. Compensation context
5. Action-oriented HR observations
